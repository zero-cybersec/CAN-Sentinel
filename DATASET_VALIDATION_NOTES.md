# Dataset Validation Notes — CAN-Sentinel

## 1. Dataset Details

Normal traffic:
- File: results/normal_traffic.csv
- Messages: 500
- Duration: 10 seconds
- Rate: 50 messages/sec

High-rate traffic:
- File: results/high_rate_traffic.csv
- Messages: 5000
- Duration: 10 seconds
- Rate: 500 messages/sec

## 2. CSV Columns

Both datasets contain:
- timestamp_s
- mode
- can_id
- data

## 3. Summary Verification

Normal traffic:
- 500 messages
- 50 messages/sec
- 4 unique CAN IDs
- Most common CAN ID: 0x300
- Observation: NORMAL-RATE PATTERN

High-rate traffic:
- 5000 messages
- 500 messages/sec
- 4 unique CAN IDs
- Most common CAN ID: 0x100
- Observation: HIGH-RATE PATTERN

## 4. Expected Behavior

- Normal dataset contains 500 messages.
- High-rate dataset contains 5000 messages.
- Both datasets use the same four-column schema.
- Summary statistics should match the datasets.

## 5. Assumptions

- Data is generated by the CAN-Sentinel simulator.
- Each simulation lasts 10 seconds.
- Configured rates are 50 and 500 messages/sec.

## 6. Limitations

- These are synthetic simulation results, not real vehicle measurements.
- High message rate alone does not prove an actual intrusion.
- These results do not establish real-world detection accuracy.
